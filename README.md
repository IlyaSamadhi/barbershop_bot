# Бот записи в барбершоп

Telegram-бот, через который клиенты сами записываются на стрижку, без звонков.

## Что умеет

**Клиент:**
- выбирает услугу с ценой → дату → свободное время → вводит имя и телефон → подтверждает;
- видит свои записи («📋 Мои записи») и может отменить запись;
- узнаёт адрес, телефон и прайс («ℹ️ О нас»).

**Владелец:**
- получает уведомление о каждой новой записи и отмене;
- командой `/admin` видит все предстоящие записи и может отменить любую.

**Защита от ошибок:**
- одно время нельзя занять дважды (даже если два клиента нажали одновременно);
- прошедшее время сегодня не предлагается, выходные дни скрыты;
- телефон проверяется и приводится к виду +7XXXXXXXXXX;
- цена фиксируется в момент записи: если владелец поменяет прайс, у уже записанных клиентов цена не изменится.

## Структура проекта

| Файл | Что внутри |
|---|---|
| `bot.py` | сам бот: кнопки, диалог записи, команды |
| `config.py` | настройки: название, адрес, услуги и цены, часы работы, выходные |
| `db.py` | работа с базой данных SQLite (файл `bookings.db`) |
| `schedule.py` | расчёт дат и свободного времени, проверка телефона |
| `test_logic.py` | проверка логики без Telegram |
| `.env.example` | образец файла с секретами |

## Запуск на Windows

1. Откройте PowerShell в папке проекта (в Проводнике: правый клик по пустому месту в папке → «Открыть в терминале»).
2. Установите библиотеки (один раз):
   ```
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в новый файл `.env` и впишите туда токен от @BotFather.
4. Запустите:
   ```
   python bot.py
   ```
5. Найдите бота в Telegram и нажмите «Старт». Остановить бота: `Ctrl+C` в PowerShell.

Чтобы получать уведомления о записях: напишите боту `/myid`, впишите полученное число в `.env` в строку `ADMIN_ID=` и перезапустите бота.

## Как поменять под себя

Всё основное в `config.py`: название, адрес, телефон, услуги и цены (`SERVICES`), часы работы (`WORK_START_HOUR`, `WORK_END_HOUR`), выходные (`DAYS_OFF`), на сколько дней вперёд можно записаться (`DAYS_AHEAD`).

## Технологии
